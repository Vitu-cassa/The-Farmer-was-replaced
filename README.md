# Algoritmos com The Farmer Was Replaced

Repositório criado para a prática de algoritmos e escrita de programas com Python.
O objetivo é criar um ambiente onde as pessoas possam interagir com programação, através deste jogo ~particularmente incrível~. E quem sabe, criar uma comunidade que queira otimizar os códigos, a ponto de subir na rankeada, sendo este último objetivo uma consequência. Apenas divirtam-se!
