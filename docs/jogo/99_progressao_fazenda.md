# 🔓 Sugestão de Desbloqueios

A tabela a seguir sugere as tecnologias para desbloquear na **Árvore de Tecnologias** do drone. São apenas sugestões — avance na árvore da forma que for mais conveniente para o seu aprendizado. A progressão do jogo adiciona novas estruturas e habilidades, mostrando na prática que o código pode ficar cada vez melhor.

> **OBS:** Esta tabela não está entre os arquivos oficiais do jogo!
